## Astrea - Kensei

This is an extended personal version of the NASA Space Apps Challenge Astrea project.

The original project was made to explore SPHEREx images across the sky. This fork has the objetive of correcting errors and adding new functionalities.
The project will also explore data from other space missions.

Original version: https://github.com/CH4P3R/Astrea---Planet-X-and-SPHEREx
